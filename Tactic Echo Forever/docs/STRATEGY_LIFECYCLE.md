# 策略生命周期与调试

适用版本：1.3.0。新增选项不改变旧配置默认行为；所有输入继续通过Runtime、Dispatch及TEF TEK。UNKNOWN或Secret不授予资格。

## 策略解释与体检

设置侧栏的“诊断/测试”页提供“策略解释”“配置体检”“事件时间线”。策略解释点击时按需采样，显示要求、公开值和三值判断；不会启动派发、更换候选、推进序列或重新武装一次触发。打开设置仍阻断输入，解释结果不能代替关闭设置后的实时复查。

配置体检检查当前已保存战斗方案；策略详情里的“体检当前条目”检查草稿。使用策略之间的布尔矛盾、互不相交的数值范围会阻止保存，草稿保留。不可达的跳过策略、无条件优先遮蔽和公开确认未学的精确ID只提示；未知技能状态不等于未学。体检不自动替换技能，也不承诺找出所有可能的组合矛盾。

时间线沿用最多128条诊断，显示最近24条，关联会话、代次、起始身份编号、起始请求、时间和推进原因。起始编号来自本会话的公开精确施法身份；请求不等于桌面端已输入，桌面执行仍须核对TEK日志。旧日志缺少的新字段显示未知，不补造历史证据。

## 触发与额度

在技能或技能组的“编辑策略”中选择触发方式：

| 方式 | 行为 |
| --- | --- |
| 持续参与推荐 | 保留普通资格判断，不新增成功额度限制。 |
| 条件重新满足一次 | 成功后不再执行；使用／跳过策略组合明确不满足后，再次满足才可执行。冷却、资源或技能可用性变化不重新武装；UNKNOWN也不重新武装。 |
| 每个目标一次 | 对公开GUID记录已完成目标；GUID不可公开时按既有目标选择周期保守回退。返回同一公开GUID仍保持已使用；同一回退周期内后来出现GUID也不重新授权。 |
| 每次战斗一次 | 仅在公开战斗状态下允许，观察到公开脱战后进入下一战斗额度；未知不制造边界。 |

技能组未设置新触发方式时，保留原有完成后等待重新触发的行为；显式选择持续参与推荐才允许连续重入。

列表循环在完成该步配置的次数后消费一次额度；优先级普通技能按一次精确成功消费。技能组仅在正常完成、至少有一次子步骤精确成功且入口上下文保持一致时消费；条件退出、人工结束和紧急退出不记作整组成功。

普通技能可选“本条目”或“同方案同技能共享”。共享按来源、职业、方案、精确ID和触发方式区分；父列表与同一来源的组内步骤可以共享。技能组本身不具有单一技能身份，仅支持本条目额度；条件重新满足一次也仅支持本条目。自动攻击6603按开启状态推进，不支持这些按精确施法成功计数的非持续触发。

暂停、继续、推荐替换及自动循环重置保留额度；显式开始重置、编辑、重置、世界切换或重载清除。额度记录最多256项，每项最多256个目标；容量不足保持阻断，不淘汰旧额度来重新授权。重复、失败、旧代次及目标／战斗上下文改变后的迟到成功不消费额度或推进。限定步骤的部分次数不跨目标或战斗累计：公开上下文改变时撤销旧身份并从本步零次开始，未知上下文保留计数并阻断。

## 技能组保持与退出

组的“编辑策略”可开启“执行期间继续满足入口策略”。组运行期间复用入口策略作为保持条件，不另建第二套条件编辑器：

- 明确满足：继续组内顺序。
- 未知：保留组内位置与次数，阻断新输入。
- 明确不满足：等待当前施法／回执解除锁定后，结束组并返回父列表，或结束组并停止派发。

返回父列表时，列表循环进入组后项；优先级重新判断。目标切换、消失、死亡及原有生命周期保护继续生效。旧配置不开启保持条件，保留原执行方式。

## 紧急规则

“增益与紧急”页中，可在条目策略详情开启“紧急规则”。它作为独立分类先于普通维护参与判断；同类仍按列表顺序。可设置精确成功后恢复原技能组位置，或结束原组并回到父列表。

紧急规则复用维护入口和输入链，仍只接纳已支持的增益／解控法术，不放宽为任意伤害、治疗、位移或打断。等待当前施法、引导及精确回执结束，不自动中断读条。脱战仍需既有手动意图资格；配置本身不启动派发。

可为生存意志1259718设置昏迷条件及“条件重新满足一次”，并标记为紧急规则。条件能否公开、技能是否已学及实际可用仍须在当前客户端验证。

## 人工接管

| 命令 | 用途 |
| --- | --- |
| `/tef explain` | 只读现场解释当前来源。 |
| `/tef check` | 体检当前已保存战斗方案。 |
| `/tef timeline` | 查看最近运行事件。 |
| `/tef skip` | 放弃当前普通列表步骤，不计成功；组内也可使用。 |
| `/tef endgroup` | 结束当前组，返回父列表，不计整组成功。 |
| `/tef restartgroup` | 从组首重新开始，必须仍有运行意图、满足当前入口资格；不清除成功额度。 |
| `/tef recheck` | 优先级重新求值；活动组先结束。固定列表保留当前位置并撤销旧请求身份。 |

人工改变进度要求关闭设置，且当前没有锁定施法／回执和活动维护。拒绝操作时保留原进度。失败或跳过不记作成功，旧身份保持墓碑保护。

“高级TEK”页的“施放非当前步骤技能后”可选择保留进度或暂停等待手动继续。这里只能确认公开的非当前技能起始，不能证明输入一定来自玩家。默认保留原进度；选择暂停时保留组内位置。手动施放当前步骤技能继续使用原精确起始／成功匹配机制。

## 实测建议

先检查旧方案的默认循环，再逐项启用新选项。分别验证条件未知、失败重试、返回旧目标、脱战再进战斗、暂停继续、条件退出组、紧急成功／失败和人工跳过。对照游戏事件、插件请求及TEK日志，不以离线模拟或推荐图标变化代替真实施放验收。
