## 验证边界

本轮增加针对心跳接线、隐藏状态、条件身份、显示详情代次、诊断摘要、字体下限、几何偏好、布局复用、探测次数和行结果隔离的回归。旧测试面板用例明确打开面板；原型用例只加载测试资料；CDM层数用例改为验证不会读取已移除的数据。

游戏内字体、提示位置、禁用态、滚动、详情覆盖及真实输入路径尚待验收；桌面构建成功也不证明前台、钩子或输入成功。不得停止或替换活动TEK。

## 实机验收建议

1. 重载后分别检查标准与迷你HUD，进入外观页，确认迷你几何设置禁用，字号以实际值调整。
2. 开启只读实时追踪，不操作页面，观察采样时刻持续变化；隐藏HUD后再检查。输入框有焦点时采样暂停，清除焦点后恢复。
3. 使用缺少观察对象的CDM条件，检查是否定位到具体策略和条件；修复观察对象后重新采样。
4. 比较明确超距和接口未知的提示；确认均保留意图并阻断输入。
5. 打开诊断页查看会话、代次、请求与所选报告；切换页签、调整窗口后检查列表和详情边界。
6. 桌面状态界面确认监控提示为未提供，保持既有活动TEK不受部署影响。
