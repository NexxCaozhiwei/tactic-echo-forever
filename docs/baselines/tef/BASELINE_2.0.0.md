# TEF 2.0.0 基线

日期：2026-10-16。以1.3.1为基础，将Studio工作台与本轮视觉修正纳入2.0.0。当前版本文件、Config、TOC、Bootstrap与更新日志同步。

## 范围与行为

- 主编辑区承载列表循环、优先级规则与技能组步骤；策略Inspector和方案设置在右侧显示，窄窗口采用覆盖方式。保存区和诊断区与滚动列表分离。
- 技能库为右侧可拖动弹窗，滚轮与滑块统一控制偏移；支持名称与精确ID搜索，只展示公开确认的已学主动技能。等级来自同槽位公开数字或匹配名称的等级文本，缺失、冲突或受保护时显示“等级未知”。成功切页关闭弹窗并清理拖动。
- 下拉控件使用兼容字体的标记，不依赖截图中缺失的特殊箭头；选中技能行边框持续高亮，悬停与移出不覆盖选中状态。Studio面板与技能行复用客户端原生圆角边框，无额外素材依赖。
- 删除工作区重复的派发设置入口；维护列表独立标识，只保留有效设置。
- 保留原会话草稿、校验、组暂存、删除撤销、保存和运行意图。UNKNOWN、精确已学ID、精确成功回执、TEAP、TEK、宏和快捷键契约不变。

## 验证边界与验收

用户在上一轮部署后反馈“UI上没有大问题”，并提供下拉缺字截图；该反馈只代表已查看的页面，不能推广为全部分辨率或真实派发通过。本轮缺字修正、选中高亮和圆角边框尚未实机验收。

交付前运行README要求的基线、Lua模拟、Python回归、TEK单测、插件工具测试、Python编译、Lua 5.1语法、中文Markdown及差异检查，结果另记于交付说明。

游戏内重载后，依次选择两个技能行并移出鼠标，确认高亮随选择转移且刷新不消失；打开持续参与推荐的下拉控件，确认文本和标记完整；检查主面板及技能行圆角在不同UI缩放下无裁切。技能库滚动、切页关闭和维护页布局继续按[整合验收步骤](../../STUDIO_ACCEPTANCE_CANDIDATE.md)复核。
