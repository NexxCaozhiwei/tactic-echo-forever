# TEF 1.1.8 基线

日期：2026-10-14。

编辑策略中支持输入新精确技能ID并点击ID替换，或拖入新技能到拖入替换按钮。列表循环、优先级推荐和增益维护均修改草稿，保存后生效；保存继续沿用停止旧派发及清除计数规则。策略条件、次数、启用状态、施放类型保留。显式配置的观察技能ID不自动改写，空白观察ID随本技能变化。

新技能必须独立公开确认已学、公开名称以及非被动资格；拒绝GCD61304与引导子事件7268。增益维护仍限定支持的增益／解控技能，拒绝重复精确ID。列表循环的名称及matchIDs更新为新技能唯一精确身份，旧技能成功不能推进新技能。保留现有UNKNOWN和回执保护，不自动推断等级。

## 验收

执行/reload，打开原技能的编辑策略，更换新技能，确认显示名称和精确ID，核对策略与次数保留后保存。再次打开及重载确认配置。若条件显式引用旧ID，按玩家意图自行调整；旧ID不因升级自动授权新ID。离线测试不证明游戏输入成功。
