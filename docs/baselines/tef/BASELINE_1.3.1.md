# TEF 1.3.1 基线

日期：2026-10-15。以1.3.0为基础，仅修复策略条件页右侧内容裁切及滚动条留白。

## 原因与改动

原表单和条件卡片宽390，滚动视口宽385，内容右侧超出视口5单位，边框被裁切。当前保留表单390宽，将视口增至394宽；视口左边距16，策略外框448宽，右侧剩余38单位供原生滚动条与外框间距使用。

并排编辑器的屏幕宽度门槛与主窗口居中偏移，改为依据策略／技能组编辑器实际最大宽度计算，空间不足时继续使用覆盖布局。不改动策略数据、资格判断、Runtime意图、回执或输入链。

## 检查与验收

新增回归检查表单右侧至少4单位余量、滚动区右侧至少32单位独立通道，以及960、1296和1600单位屏幕宽度下的覆盖／并排布局。已通过README规定的独立契约检查、301项运行模拟、264项APL模拟、235项Python测试及17项子测试、229项TEK单元测试、2项插件工具模拟、Python编译、52个Lua文件的5.1语法和差异格式检查。159个Markdown文件完成中文自然语言审查，保留参考文档中的2条原始APL代码行。离线几何检查不证明游戏内原生滚动条贴图及视觉已通过。

游戏内执行 `/reload`，打开技能策略，添加至少一条策略并滚动到上下两端。检查条目边框、按钮右缘完整可见，滚动条与内容、外框互不遮挡；窄屏覆盖模式也应保持完整显示。
