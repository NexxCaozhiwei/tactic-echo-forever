# TEF 1.0.17 — 序列编辑体验修复

## 拖入人工序列

法术书游标使用第四个返回值的精确技能 ID；动作栏游标使用公开槽位的 GetActionInfo，且只接纳类型为 spell 的直接技能。宏、物品、受限槽位、受限类型及未知 ID 不猜测。读取失败、草稿无效或超过 16 步时不清除游标、不修改草稿；成功新增后才清除游标。

推荐配置页面、列表空白和滚动子内容支持追加；已有行及次数、排序、删除和跳过控件可接收拖入，在该行之前插入。持有技能后点击页面空白或行也可新增；无游标的普通点击静默处理，避免覆盖新增成功提示。所有编辑仍只改草稿，保存后沿用原有停止和重置规则。

## 窗口与界面

主设置窗口保持 820 宽，高度从 600 增为 720。人工序列和高级文本视区从 226 增为 346，操作按钮和提示下移 120。自定义 APL 规则列表从 94 增为 154，条件视区从 220 增为 280；诊断与提示同步下移，派发总览和 HUD 外观滚动视区扩大。

删除推荐配置的射击5019快捷新增按钮及自定义 APL 的魔杖提示文字；保留精确输入、已保存序列以及既有射击计数/交接兼容。

设置窗口使用 MEDIUM 层级，Toplevel 为 false；不新增 Raise 或提升层级逻辑。窗口拖动及打开设置时的派发阻断保持。

## 验证

新增 4 项拖入回归：动作栏直接技能解析与原次数保持，宏/物品/受限槽位/未知 ID 拒绝，空白与持有游标点击只新增一次，以及行内控件拖入不执行原编辑操作。

完整项目检查、241 项 Lua 模拟、235 项 pytest 测试及 17 项子测试、两套 unittest、Python 编译检查和 40 个 Lua 文件的 Lua 5.1 语法检查通过。

实机待验：从法术书与动作栏拖入列表空白和行；保存并重新打开检查顺序与次数；同时打开法术书确认不会被设置窗口强制遮挡；检查增高后的按钮、提示与滚动区域在当前屏幕缩放下可见。离线测试不代表实机交互已通过。
