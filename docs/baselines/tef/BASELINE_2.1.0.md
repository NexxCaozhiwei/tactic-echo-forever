# TEF 2.1.0 基线

日期：2026-11-10。继承[2.0.1基线](BASELINE_2.0.1.md)，纳入此前后续修复及本轮方案分享、动作条等级校准功能。VERSION、Config、TOC、Bootstrap、更新日志及入口文档同步为2.1.0。

## 新增及整合

- `TEFPLAN:1:`分享单套列表循环或优先级方案，含未保存草稿、名称、技能组和策略。
- `TEFPOLICY:1:`分享单项使用／跳过条件，保持目标技能ID、次数、顺序、施放类型、触发行为及显式观察ID。
- `TEFBUNDLE:1:`分享当前职业六套方案；导入草稿后可统一保存，全部六槽清洗和审计通过才写入。
- 分享码有版本和损坏校验及长度、结构和容量限制，不执行输入文本。不同职业或命名空间拒绝混用；过期目标及取消覆盖不改原草稿。
- 导入与导出输入底板固定164高，内部148高滚动区，空白区域可点击聚焦；分享窗口复用同一套控件。
- 等级校准只采用动作条公开精确技能或可核对宏，独立确认已学、主动与派发绑定。同族名称只用于发现，不按最高等级或ID大小替换。批量覆盖当前方案及组内技能，确认时复核动作条与草稿。
- 纳入标准、三图标简略、单图标最小HUD切换及主图标拖动；状态点绿色代表派发意图开启、红色代表关闭，待命仍为绿色。
- 技能组上限36步，父列表16项；保留精确成功推进、回执身份及有界循环语义。修复布局刷新后列表策略面板无法恢复显示。
- 继承此前接续窗口独立设置、候选只读预热、窄尾窗唤醒、引导停止复核与分段送达诊断，具体边界见[接续说明](../../DISPATCH_TIMING_V4.md)。

## 保存与运行边界

导入和等级替换只修改会话草稿，不启用方案、不改变运行来源或开启派发；重载前须显式保存。统一保存停止旧派发，保持启用状态、当前方案选择、HUD及派发参数。所有实际输入仍复用Runtime、Dispatch、TEAP与TEF TEK，未知不能授权输入，不改绑定、宏或WTF。

## 验证与未测范围

本轮提交前执行README规定的基线检查、Lua模拟、Python回归、TEK与交付单测、编译、全部Lua 5.1语法、中文Markdown及差异检查，结果以交付记录为准。新增回归覆盖方案及36步组往返、策略四种编辑来源、整包六槽保存与重载、失败不部分写入、动作条等级歧义及确认期间变更。

游戏内长文本复制粘贴、不同分辨率和缩放、控件遮挡、点击穿透、全部职业等级、完整引导末跳及真实输入仍需分别验收。程序构建或启动不证明钩子、SendInput或游戏施法成功。

发布产物放在dist，包含单根目录完整源码ZIP和SHA256。发布构建使用干净检出，不启动第二个输入实例，不停止或替换活动TEK。
