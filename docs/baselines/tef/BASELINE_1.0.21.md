# TEF 1.0.21 — 人工序列按目标与战斗限制使用

## 配置与使用

人工序列每行新增使用策略按钮，点击依次切换“每轮使用”“同一目标只用一次”“同一战斗只用一次”；修改草稿后须保存。旧配置默认每轮使用。高级文本支持205:205*3!skip!target及205:205!combat，复制、解析、排序和保存均保留策略。

限定的是单个步骤，只有该步骤配置的次数全部成功完成才登记。失败、不可用跳过和阻断不消耗资格。6603沿用公开自动攻击开启一次的确认语义，不伪造施法成功；其他技能使用精确成功回执。

## 目标与战斗范围

同一目标使用公开、规范化后的UnitGUID身份；首次ABCD完成后，同一目标后续循环为ACD。换新目标可重新使用B，切回已登记目标仍跳过。每个步骤独立登记；同一技能的两个不同步骤不共享资格。

同一战斗使用公开战斗状态及本次战斗代次，换目标不恢复B；确认从战斗中退出后清空战斗记录。脱战手动起手的完成记录延续到随后进战，首次确认脱战后恢复。UNKNOWN或Secret不作为新目标、脱战或可用资格。

暂停及恢复保留记录；自然循环、按目标或战斗自动重置序列位置也保留尚有效的记录。编辑、主动重置、重新开始、世界切换或reload清除记录。限定步骤的部分次数不会跨目标或战斗范围累计；已接受的旧回执仍受代次、索引及回执序号保护。

目标记录只存在运行期，不写入SavedVariables，最多256个目标且每个最多16个步骤，不淘汰旧记录后放行。达上限时阻断并提示主动重置；所有限定步骤都完成时等待范围变化，不空循环。

## 运行链路

沿用Runtime.intent和既有心跳，新增SequenceUsage负责资格和登记；Runtime在门禁确认后有界跳过已完成步骤。派发请求、最终Packet及读条末尾排队核对资格和来源范围。排队保留独立起始身份与范围，不预先登记成功。

自定义APL行为保持现有规则。未新增定时器、输入路径、宏、技能绑定、WTF写入或协议变更；未修改或替换活动TEK。
