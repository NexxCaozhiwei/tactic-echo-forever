# TEF 1.1.3 基线

日期：2026-10-14。依据1.1.2会话24、25的公开姓名板物品探针证据，将码数统计接入策略资格，不把采样附近的魔爆成功当作实际命中数证明。

## 设置和迁移

条件菜单统一为“自身范围内可见敌人数”。填写以玩家为中心的码数（大于0且不超过40）与敌人数上下限（0～40整数，含边界），不再填写范围技能ID；玩家无需逐个选择姓名板。

旧rangedEnemies条件保存或重载时转为nearbyEnemies，未指定码数默认10码，数量上下限保留，旧范围技能ID移除。原nearbyEnemies条件保留原码数，取消只读限制。默认10码不代表魔爆术实际作用半径，玩家应按需要设置。

## 判断语义

- 只统计当前可见、存活、敌对的姓名板，以公开物品探针区间判断是否在设置码数内。
- 公开上界不超过码数为确定在内；公开开区间下界不小于码数为确定在外；其余未确认单位计入可能数量，不当作零。
- 确定数量为lower，确定数量加未知项为upper。数量上下界整个满足配置区间才返回真，整个不满足才返回假，跨阈值返回UNKNOWN。
- 例如至少2只：lower=2、upper=3为真；lower=1、upper=1为假；lower=1、upper=2为UNKNOWN。若还设置最多2只，lower=2、upper=3则UNKNOWN。
- 使用策略仍须满足本行精确已学、公开可用、资源及范围门禁；跳过策略只有公开确认为真才匹配。战斗／脱战输入授权、引导与魔杖门禁保持不变。

## 有界执行和验证

沿用最多40个姓名板、4种码数、现有0.05秒脏合并／0.20秒兜底刷新及派发前复查。不新增定时器、钩子或输入路径。记录数量上下界、未知数及身份／探针详情，保护Secret不被比较或持久化。

模拟覆盖旧配置迁移、保留码数、数量区间上下限、UNKNOWN的使用／跳过行为、编辑保存和范围变化撤销派发。当前客户端已观察到10码数量3→2→0及2→1→0，未知项0，证明该探测路径可公开工作；其他码数、新策略自动消费与实际AoE命中关系仍需实机验证。离线测试和部署不证明游戏成功。

## 部署后用户验收

2026-10-14，部署1.1.3后，用户反馈“测试通过”，确认“自身范围内可见敌人数”接入当前APL策略的游戏内测试通过。该反馈不扩展为所有码数、所有职业或实际AoE命中数均已验证。
