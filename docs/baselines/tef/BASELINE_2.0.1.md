# TEF 2.0.1 基线

日期：2026-10-19。继承[2.0.0基线](BASELINE_2.0.0.md)，纳入审查清单1～16项整改、增益维护复位修复和逐项复查后的三处修复。VERSION、Config、TOC、Bootstrap、更新日志同步为2.0.1。

## 当前变更

- Studio只读实时追踪复用独立显示心跳，隐藏HUD或关闭信号不使其停止；焦点占用或未知时暂停采样。
- 策略结果显示具体策略、条件和观察ID，区分确定阻断与未知；诊断摘要与报告同时显示。
- 标准HUD260×108，迷你156×60；迷你固定几何设置禁用，字号按实际显示范围调整，旧偏好兼容。
- 合并重复布局、技能行显示及同次冷却探测；隐藏旧练习面板不刷新，删除失效层数实现，历史优先级原型仅由测试加载。
- 增益维护在施法或设置锁定期间继续按原节拍观察条件复位，锁定解除后才允许替换推荐；成功去重、原列表进度和精确回执保护保留。
- 页面刷新、Studio刷新与布局异常均释放重入标记，并清除可能未完成的缓存；小视口布局签名包含缩放值。
- CDM精确帧必须公开可见才读取活动状态；隐藏、可见性缺失、受限或调用失败保持未知，不授权使用或跳过。精确身份、冲突和容量限制保留。
- TEK缺少监控数据时显示未提供；不自动停止或替换活动TEK。

## 契约与验收边界

运行意图、手动脱战维护授权、精确已学ID与成功回执、状态分层、TEAP线格式及唯一输入链不变。不新增输入路径或定时器，不修改玩家宏、技能绑定或WTF。

此前[逐项复查](../../CODE_REVIEW_RECHECK_2026-10-19.md)记录的三个问题已在本版本修复；该报告保留发现时证据，后续修复结果在报告末尾补充。离线模拟不证明真实游戏字体、拖动、重复补增益、钩子或输入成功；这些行为仍待实机验收。

## 检查与发布

提交前执行README规定的基线、Lua模拟、Python回归、TEK及交付单测、编译、Lua 5.1语法、中文Markdown和差异检查。发布产物放在dist；完整源码ZIP只有一个根目录并附SHA256。实际结果在交付完成后补充，不预先标记为通过。


检查结果：独立基线、主Lua模拟336项、APL及关联模拟314项、Python回归238项及17个子测试、TEK单测232项、插件交付单测2项、Python编译、60个Lua文件的5.1语法、168份Markdown语言扫描和差异检查通过。新增回归证明刷新异常后可恢复、缩放缓存会更新，隐藏CDM条件在选取与派发前实时复查时均不能获得资格。真实游戏验收仍未完成。


## 2026-10-20：HUD透明度开发变更

在现有2.0.1上增加底纹及外框独立透明度，0%不透明、100%完全透明，标准与迷你HUD共用并持久化。旧配置默认保留底纹0.94、外框1的颜色透明度；内侧装饰框保留原0.65比例。仅改变外壳贴图，不改变父框架、技能图标、图标边框或文字；不改变运行资格与回执。游戏内外观仍待验收，不把离线回归标记为实机通过。
