# TEF 1.0.19 — 自身技能与窗口修正

## 自身技能

人工序列查询公开技能元数据；minRange和maxRange均为0、技能帮助标记为true、伤害标记为false，才认定为自身技能。现代元数据缺失时可使用旧GetSpellInfo，但其返回的精确技能ID必须与请求ID一致；现代范围为Secret时不得通过旧接口绕过。

自身技能不要求敌方目标及对敌方的技能范围。仍须确认输入焦点为空、技能可用、资源足够、运行意图、战斗模式、技能或宏键位，并沿用精确回执。审判及其他目标技能保持既有目标和范围检查；不知道是否自身时不猜测，不按静态圣印ID、技能名或等级别名授权。

APL的既有显式自身目标分类继续生效。Runtime状态日志保存当前步骤精确ID，帮助后续阻断复查。落盘定位见[会话5排查](../../FIELD_REPORT_2026-10-13_TEF_1018_S5.md)。

## 窗口

设置窗口使用MEDIUM、Toplevel=true和打开时一次Raise。相较1.0.17，保留点击提升；相较1.0.18，取消HIGH跨层级覆盖。刷新和心跳不执行Raise，不添加窗口钩子或输入路径。

## 验证

新增7项回归，覆盖圣印成功后审判仍受范围限制、无敌方目标的公开自身技能仍检查可用性/资源、受限帮助或伤害分类/范围拒绝、旧帮助标记、自动脱战零输入、元数据变更撤销请求，以及旧元数据精确ID核对和Secret不回退。

完整项目检查、257项Lua模拟、235项pytest测试及17项子测试、两套unittest、Python编译和43个Lua文件的Lua 5.1语法检查通过。

实机待验：十字军圣印20162能否按当前客户端公开元数据分类和派发；成功后是否转到审判，超距审判是否仍阻断；法术书与其他普通面板唤起后是否覆盖插件，点击插件后是否恢复到前面。上述离线验证不代表实机效果已通过。
