# TEF 1.2.0 基线

日期：2026-10-15。以1.1.12为前一基线，收口技能组首版、右侧编辑交互、距离档位和起手／循环修复；不变更TEAP协议或桌面输入路径。

## 功能范围

- 列表循环及优先级推荐各有三套独立方案，支持名称、排序及共享策略；默认择一运行，保留增益维护优先级及手动启停。
- 两种战斗来源可以新建嵌入式技能组，每组最多8步，每步1～99次、循环1～99轮，不嵌套。组策略控制进入，子步骤精确成功推进，完成后返回父列表。
- 右侧组列表提供外框、拖入追加／插入、排序、次数、不可用跳过、单技能策略、保存、清空和退出。切换策略前保存并关闭组编辑；保存失败不切换。
- 父列表循环不再绕过组轮数。公开手动起始符合当前组及策略时接续同一精确成功回执，避免重复首发；优先级冲突、失败、旧身份、受限身份或无起始成功不能推进。
- 引导末项成功后等待公开引导结束再推进组轮数。增益维护插入后恢复组内进度，战斗技能组不取得脱战输入资格。
- 周围敌人数半径使用5、10、20、25、30、35、40码固定档位；保留旧半径并提示重新选择，探针未知不视为条件满足。

## 验证证据与限制

会话54、56的落盘确认首发奥术冲击被标记为 `GROUP_NOT_ENTERED` 后重复释放，且父列表循环导致组一直停在第1轮；本基线修复这两条路径并补充回归。会话55没有相关成功施法记录。没有三份完整独立快照，分析使用当前文件、备份及保留的三个会话记录。

最近10码敌人数条件出现有效探针结果并记录魔爆术成功；8码曾全部未知。其他物品档位、所有职业技能及新增组派发没有完整逐项实测，不声明全部通过。

本地检查通过：独立契约、301项运行模拟、217项APL模拟、235项Python测试及17项子测试、229项TEK单元测试、2项插件工具模拟、Python编译、51个Lua文件的5.1语法、中文文档及差异格式检查。测试中的故障注入和输入模拟不代表真实游戏输入。

## 实机复核

执行 `/reload`，同一目标配置冲击一次、飞弹一次及三轮，手动起手后观察30～60秒。确认首发计入、顺序交替、引导不被下一轮打断、轮数准确及完成后返回父列表。随后检查停止继续、目标变化、条件未知、增益维护插入和两种来源切换，落盘核对精确成功与组进度。

安装版本和源码哈希一致仅证明部署完成；最新修复的实际游戏效果仍待用户复核。
