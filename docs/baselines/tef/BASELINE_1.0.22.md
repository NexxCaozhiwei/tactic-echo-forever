# TEF 1.0.22 — 目标身份受限时的选择周期计次

## 修复

1.0.21的同一目标策略仅接受公开UnitGUID，身份无法读取时会阻断整个限定步骤。会话10第1步20162记录SEQUENCE_USAGE_CONTEXT_UNKNOWN且request为0；有效目标距离记录未带公开GUID，具体原始返回原因未落盘，不能断言必然为Secret。

1.0.22先公开确认UnitExists为true，再使用当前目标身份。公开GUID仍支持识别切回已完成的目标；GUID无法读取时，使用PLAYER_TARGET_CHANGED事件界定的本次目标选择周期。该备用身份不是怪物永久身份，切换后重新选中同一只怪也算新的选择。

已经采用选择周期后，即使GUID后来公开，本次选择也保持原身份，避免同一目标途中恢复已消耗资格。已经获得公开GUID后暂时受限，可在未收到目标切换事件的同一选择中保持已知身份。收到目标变化事件立即清理当前选择关联，保留已登记的历史记录；所有切换和公开API重入仍核对代次及选择序号。

目标不存在、存在状态未知、公开API查询期间发生目标切换或生命周期变化均不授权派发。不得比较、格式化、索引或保存受限GUID。备用记录仍受256个身份上限、步骤次数及精确回执保护，不推断技能就绪。

新增4项回归，覆盖受限GUID选择周期、nil/失败/缺失接口、目标不存在、GUID途中公开及读取过程的目标事件重入。原目标存在未知回归继续要求零输入、零计数。
