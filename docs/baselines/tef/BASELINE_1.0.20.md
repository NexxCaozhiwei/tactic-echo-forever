# TEF 1.0.20 — 普通攻击开启确认与范围修复

## 普通攻击步骤

按用户选择，人工序列的攻击6603只执行一次开启确认：核对当前精确动作槽公开处于自动攻击状态后，立即进入下一步。次数固定为1，不统计平砍命中，不伪造SENT、SUCCEEDED或GUID。已经开启时不重复发送按键，避免关闭自动攻击；无按键的动作槽只能用于只读确认。

确认保持Runtime.intent、公开战斗状态、设置、许可、有效敌方目标及代次/索引/回执序号门禁。自动脱战待命可确认玩家手动开启，但输出零Token；主动暂停、设置打开及未知状态不推进。生命周期失效退休旧身份，保留容量保护。只有启动步骤的循环不持续空转。

## 相似技能

6603开启不要求近战命中范围，开启状态不证明命中。普通目标技能的范围接口公开无数据或缺失时，允许核对精确动作槽的公开范围；明确超距、Secret或调用失败不借其他接口绕过。投掷2764仍按实际精确成功回执计数。

射击5019保留固定次数及交接门禁；自动射击75增加公开自动重复状态检查，已开启或未知时不重复按开关。75不采用6603的开启即推进语义。6603、5019、75均不做不可用跳过或读条末尾预测。

既有宏中的/startattack只有在宏接口也公开确认精确6603身份时才接纳；/stopattack不作为开启来源。不创建或修改宏、绑定、WTF或桌面TEK，协议保持不变。
