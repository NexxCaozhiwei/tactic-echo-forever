# TEF 2.5.0 基线

日期为2026-11-27。本版继承 [2.1.2 基线](BASELINE_2.1.2.md)，整合 Studio 开门键、HUD 点放和保存派发意图的改动。

## 当前行为

- 「TEK 与施法接续」可设置两个独立开门键。脱战时首次按键启动15秒进战窗口，进战后继续到脱战。超时或脱战时关闭临时派发，恢复开门前的派发意图。临时开门期间固定列表走完可回到首步。
- HUD 主图标普通左键尝试派发一次当前符合条件的技能，公开脱战可用。Ctrl＋左键启动持续派发，右键进入设置。普通左键保留持续派发意图，通过同一帧的新鲜度防止重复发送。
- 所有方案保存入口保留原派发意图，废弃旧请求与回执关联。保存保持当前选用的方案，关闭设置后按新配置重新复核。
- 支持读取公开实际冷却、会话观测及基础冷却用于填充人工内置 CD。0秒关闭，未知时保留当前值。组入口人工 CD 与组内各步骤分别编辑。
- 普通与组内尾窗的未分类主动技能使用公开已学身份、施法信息及单位范围复核。旧有条件、精确回执、窗口和重放门禁继续适用。

## 兼容与验收

- 目标客户端为 Forever／Infinite 1.60.1，插件版本标识为2.5.0。开门键及点放继续走现有 TEAP v3，半自动和抢占仍要求已配套的 TEK。
- 回归覆盖快捷键录入及覆盖、超时后恢复自动待命、脱战 HUD 单次请求及去重、保存前后的开启和关闭状态，以及旧回执隔离。
- 游戏内快捷键、持续输入、具体技能接续和各分辨率的界面效果仍需单独验收。离线测试和部署哈希仅记录各自的结果。
