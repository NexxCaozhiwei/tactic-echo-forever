# TEF 1.1.1 基线

日期：2026-10-14。基于独立项目1.1.0增加六类策略条件，保留原分层、TEAP v3及TEF TEK输入链，不新增定时器、钩子或输入路径。

## 条件与用法

- 战斗状态：战斗中／脱战，依赖公开战斗状态；策略不扩大脱战派发授权。
- 当前目标类型：敌对／友方／自己／无目标。只检查当前目标，不选择或切换目标，目标存活及施放资格仍独立检查。
- 指定技能已学：填写精确SpellID，空白检查本行技能。只读取公开已学布尔值，不从技能名称、目录或最大等级推断。
- 精确成功使用记录：本轮已成功／本轮未成功，ID空白为本行技能。本轮以开始／重置／编辑／重载为边界，不是战斗次数或目标次数；暂停及候选替换保留。只记录TEF现有执行链接受的精确成功，非当前动作、失败、重复及延迟旧回执不计入。最多128个不同技能，容量饱和后的未记录技能为未知，不淘汰旧记录。
- CDM增益层数：精确增益目录ID及层数上下限，含边界。只读取可见、活动匹配帧的公开光环数据applications，光环数据自身spellId也必须精确匹配；未显示数字不等于零。Secret、隐藏、缺失、身份不符或冲突保持未知，不从层数推断光环不存在。
- 范围内可见敌人数：填写范围检查技能ID（空白为本行技能）及数量上下限。统计可见、存活、敌对姓名板中公开满足该技能范围的单位，最多40个。任何候选单位身份、敌对／存活或范围状态未知时整体未知；只代表技能射程内可见单位，不代表实际AoE命中数。地面／自身技能不能公开检查单位范围时，应另选已学的范围检查技能。

## 有界采样与诊断

每技能最多8条策略，每策略最多8个条件，最多16条技能规则。额外已学与范围探测身份合计最多16个，重复观察复用；沿用0.05秒合并和0.20秒兜底刷新。派发前重采当前行条件；公开范围退出后撤销Token。每行最多保存16条条件观察，保留Safety清洗。

策略条件窗口可滚动选择全部类型。列表循环、优先级推荐和增益维护复用相同条件结构，但各自的输入门禁和授权不变。

## 验证边界

离线回归覆盖配置往返、Secret、精确身份、成功回执和生命周期、CDM隐藏／缺失／冲突、范围未知及派发前撤销。模拟、源码或部署哈希不证明游戏内新条件成功；需要当前客户端逐项实测。
