# TEF 2.1.2 基线

日期为2026-11-12。本版继承[2.1.1基线](BASELINE_2.1.1.md)，调整 Studio 布局和编辑入口。

- 主窗口最大宽度为1120，显示技能列表和全局操作。策略副窗贴在主窗右侧外边缘，宽度不足时两窗一起缩放，可独立收起。
- 技能列表在空间充足时采用单行布局，窄屏保留第二行。设置、HUD 和 TEK 内页按可用宽度排版，技能库可通过标题栏拖动。
- 版本文件、Config、TOC、Bootstrap 和更新日志同步为2.1.2。派发与回执契约沿用前版。

验证覆盖宽窄窗口、控件边界、副窗停靠、收起副窗后的草稿保留和主窗口保存入口。离线模拟、文件核验及桌面程序启动检查不代表真实游戏派发成功。实际客户端字体、缩放和拖动效果仍待验收。
