# TEF 2.1.1 基线

日期：2026-11-10。继承[2.1.0基线](BASELINE_2.1.0.md)，补齐增益与紧急的整包迁移。版本文件、Config、TOC、Bootstrap及更新日志同步为2.1.1。

## 本轮变更

- `TEFBUNDLE:2:`包含当前职业六套方案及增益与紧急完整列表、策略、条目启用状态和紧急行为；维护总开关、本机绑定及派发设置不导入。
- 旧版`TEFBUNDLE:1:`继续导入，缺少维护内容时保留本机列表；新版显式空列表可清空维护草稿，不将缺失当作空配置。
- 维护页提供全部导入／导出／保存入口，导入只写草稿。统一保存先校验全部内容及维护技能资格，通过后才重置并统一写入；无效维护条目不能导致其他方案部分保存。
- 原维护单独保存与整包保存共用资格校验，保持只接纳增益与已支持解控法术，不允许维护技能组、重复ID或未知资格绕过。

## 验证边界

交付前运行README要求的检查及Lua 5.1语法检查。新增回归覆盖维护策略与紧急行为往返、总开关开关两种状态、维护页草稿与重载、旧版兼容及保存失败不部分写入。离线、构建和部署校验不证明实际增益／紧急输入成功。

游戏内新增入口、复制粘贴、不同缩放及实际增益与紧急运行仍待验收。发布产物从同提交干净检出构建，不停止或替换活动TEK。
