# TEF 1.1.0 基线

基线日期：2026-10-13。本版收敛独立 Forever 项目当前实现，包含 1.0.23 设置改版之后的普通读条持续派发、自定义策略窗口、全职业自定义技能支持及 HUD 候选预览。不把版本发布、本地部署或模拟通过等同于完整实机验收。

## 配置与设置

- 派发总览选择人工序列或自定义 APL；每种来源各有三个独立方案，同时择一运行。首次选择并启用方案一，其他方案须显式启用。
- 人工序列提供循环、重置、次数、不可用跳过及每目标／每战斗限制。场景验证、诊断测试导航隐藏，底层诊断保留。
- APL 方案标签独占一行，ID 输入与新增位于拖入技能后。列表增加明显外框，支持拖拽、上下箭头和删除。
- 编辑打开主设置窗口右侧策略条件窗口，支持新增／删除策略、增删条件、保存和清空。旧条件保留严格比较语义迁移，保存停止派发。
- 每个技能最多 8 条策略，每条最多 8 个条件，整套最多 16 个技能。每条条件以 AND 组合，所有使用策略必须成立；任一跳过策略成立则跳过。未知不授权，继续检查后续技能。
- 条件包括技能可用性、技能范围、目标距离、移动、实验性可见敌人数、CDM 冷却、CDM 增益和自身冷却活动；可同时配置多个 CDM 精确目录 ID。

## 技能与派发

- 自定义 APL 不再依赖法师职业包或伤害技能名单。支持各已登记职业的精确已学主动技能，保留技能可用、资源、射程、战斗及输入资格检查。
- 自动目标类型依赖已登记语义或公开技能元数据；无法确认时等待，允许用户明确选择自身、友方、敌方或地面。被动、身份缺失及受限状态不放行。
- 友方目标必须合法、存活且在技能射程内；无友方目标时，自身路径需公开确认游戏自动自施法开启。地面技能由玩家操作落点，选点中或状态未知阻断重复输入。
- 普通读条默认持续输出当前推荐。公开起始保留精确回执身份，只有精确成功推进；同技能提前起始保留独立接续身份，不预测成功。
- 引导开始立即撤回输入并锁定；停止事件解除事件锁后仍需实时查询确认无引导。魔杖、自动攻击与自动射击保留开启门禁。
- 固定序列末尾排队仍使用公开配置窗口与客户端窗口的较小值，上限 0.50 秒；不用于 APL、引导或魔杖预测。
- TEK、线协议、输入路径及频率门禁保持原有契约。未停止或替换活动 TEK，不修改宏、绑定、目标或落点。

## HUD

有目标时，保留主推荐并展示优先级靠后的合格技能。只有 A 显示 AAA，只有 A、B 显示 ABB；无目标时按配置优先级展示。人工预览不推进序列；APL 回执锁定期间使用既有刷新入口更新只读预览，不能修改运行意图或创建输入请求。图标尺寸与间距继续支持滑块和限定范围整数输入。

## 验证范围

发布检查覆盖独立契约、299 项运行模拟、150 项 APL 模拟、235 项 Python 测试及 17 项子测试、229 项 TEK 单元测试、2 项插件工具模拟、Python 编译及 46 个 Lua 文件的 Lua 5.1 语法检查。部署需独立校验 41 个运行文件。

已落盘证据确认旧版奥术智慧 1460 因 `CUSTOM_SPELL_UNSUPPORTED` 被阻断，策略配置已保存；本版解除该名单限制并补目标类型契约。尚无本版全职业技能、地面选点、全部 CDM 身份或最新 HUD 页面交互的完整实机验收。10 码姓名板敌人数统计尚未实现；可见敌人数不是区域内敌人数或实际命中数。法力百分比、生命百分比、真实光环层数及剩余时间仍未作为规则条件接入。
