# TEF 1.3.0 基线

日期：2026-10-15。以1.2.4为基础，增加策略生命周期与只读调试功能，不变更TEAP线格式、桌面输入路径及原有Secret／UNKNOWN契约。

## 实现范围

- 策略解释按需只读采样；保存前检查可证明的使用条件矛盾，其他问题提示。事件时间线关联会话、起始编号与请求；不推断桌面输入已执行。
- 显式持续、条件重新满足、每目标、每战斗触发与普通技能共享额度；精确成功消费，容量不足阻断，暂停和推荐替换保留额度。组额度在正常完成且有子步骤精确成功时消费。
- 技能组可复用入口策略作为保持条件，未知保留进度并阻断，明确不满足后返回父列表或停止。
- 紧急规则作为维护列表中的独立分类，先于普通维护；等待当前施法与回执结束，成功后可恢复或结束原组。不增加自动中断施法能力，不扩大原技能接纳范围。
- 人工跳过、结束组、重开组及重新判断；非当前技能公开起始可选择暂停保留进度。不能判定实际输入来源，不把人工跳过视为成功。
- 旧配置默认行为保持；新增界面复用现有有界表单池与滚动容器，无新增定时器、钩子或输入通道。
