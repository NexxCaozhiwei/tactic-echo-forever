# TEF 1.0.23

收敛设置界面改版。派发总览选择来源，人工序列页提供循环/重置；诊断测试与场景验证导航隐藏。两种来源各有三个独立方案，首次启用并选择方案一，其他默认停用。旧单体和多目标配置保留为方案一和方案二，第三方案为空；重载保留后续用户保存的选择。

方案切换通过既有来源选择、重置及回执失效流程；关闭当前方案会停止意图，停用方案不能使用。人工和APL的第三方案分别保存，不互相覆盖。移除变形术ID确认与高级文本入口；内部文本载体仅为草稿序列化。旧超限行保留，需逐行删减至16步。

HUD几何项提供滑块和整数输入：主图标32–112，预览图标24–96，间距2–40。无效值不改变配置，显示允许范围；战斗中仍延后布局。

295项Lua模拟、135项APL模拟、完整README检查及Lua 5.1语法通过；部署文件核验与实机验收分开。游戏内布局、保存重载和方案切换仍待用户验收。不调整普通读条、引导锁、排队窗口或TEK连发行为。

详细交互与迁移说明见[设置界面改版说明](../../SETTINGS_REWORK_DRAFT.md)。
