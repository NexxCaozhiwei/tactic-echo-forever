# TEF 1.0.18 — 自然窗口顺序与现有技能宏

## 窗口顺序

设置窗口使用 HIGH 和 Toplevel，打开时 Raise 一次，点击时由游戏调整同层顺序；普通刷新、心跳与页面切换不反复提升窗口。其他游戏面板唤起后的遮挡顺序遵循游戏层级；模态或更高层窗口继续遵循游戏自身规则。实际法术书和其他窗口的前后切换需要实机确认。

## 宏识别

参考本机原 TE 插件 Actions/ActionBarBindingResolver.lua 的当前宏身份、代表技能 ID 与正文引用核对原则，独立实现 ActionSources.lua；不导入原 TE 运行模块、设置或映射。

支持法术书直接技能、动作栏直接技能、宏游标与动作栏宏。宏须在当前公开宏目录中，GetMacroInfo 的名称及正文可公开读取，GetMacroSpell 返回公开精确技能 ID，且正文包含该技能施法引用。支持旧式第三返回值和新版首返回值数字形态；两者冲突时阻断。

识别 /cast、技能形式的 /use、/castsequence 和 /castrandom 的正文引用。条件、序列状态和实际施放由游戏决定，不推断宏内目标或分支，不把提示图标当成施法证据；精确技能等级由公开宏技能 ID 与已有已学技能门禁确认。

动作栏若返回代表技能 ID，通过当前公开标签、宏名称及精确技能恢复唯一宏；可见标签为技能名称时仅接纳唯一经正文核对的候选。同名同技能或同显示技能存在多个候选时阻断。目录总数有界，稳定目录仅缓存运行期公开身份，UPDATE_MACROS 后清理。

人工序列和自定义 APL 的拖入使用共同解析入口，保存精确技能 ID；HUD 与 TEK 使用该宏在当前动作栏已有的键位。每次请求及最终发布都重新核对宏身份、正文、公开技能和键位，变更后撤销请求。

不创建或修改宏、技能绑定，不执行宏正文。正文仅在运行期用于身份校验，不写入 TEF_DB、日志或导出。沿用原 TEAP v3、Runtime.intent、手动输入优先和精确施法回执；未知、受限、正文不可读、目录或身份歧义时阻断。

## 验证与待验

新增 9 项回归，覆盖两种宏技能 API 返回、仅图标/错误正文/受限信息拒绝、代表技能与名称恢复、重复宏歧义、角色宏索引、正文/键位/技能变化撤销、两个编辑器拖入、UPDATE_MACROS 撤销、重复次数精确回执，以及窗口只在打开时提升而不在刷新时抢前台。

完整项目检查、250 项 Lua 模拟、235 项 pytest 测试及 17 项子测试、两套 unittest、Python 编译检查和 42 个 Lua 文件的 Lua 5.1 语法检查通过。离线验证不证明宏输入、技能命中或窗口实际顺序。

实机步骤：放置并绑定一个已有技能宏，拖入人工序列和自定义 APL，核对 HUD 键位；修改宏正文或键位检查旧请求撤销；按实际成功回执检查次数。分别打开插件设置、法术书和其他窗口，再点击插件检查自然前后切换。
