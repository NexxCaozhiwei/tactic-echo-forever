# TEF 1.2.3 基线

日期：2026-10-15。以前一基线1.2.2为基础，落实七项页面布局反馈；不改变距离探针、UNKNOWN阻断、TEAP协议或技能派发链。

## 策略编辑器回归修复

用户反馈更换、升级及条件区全部消失。检查时安装目录为1.2.1；复用池清除表单锚点，而构建未显式恢复。当前修复在SetScrollChild后重新锚定，并在成功后缓存索引；构建失败不删除草稿、不缓存失败结果，重新打开可重试。滚动偏移按新表单高度限制，避免空白视口。

严格模拟令同一滚动子对象再次绑定不自动恢复锚点；负对照禁用显式锚定时重现缺失，恢复后定位正常。重复重建、更换／升级控件及条件引用、构建失败重试和滚动范围通过回归；实际游戏结果仍需reload复核。

## 页面改动

1. 派发总览按派发状态、运行模式、当前配置、派发启停快捷键排列。移除已有绑定覆盖开关及hotkeyOverride清洗授权；旧字段无法绕过冲突检查，TEF仅用既有临时绑定API注册未绑定按键，不改原技能绑定。
2. 列表循环显示中文职业名称；内部CLASS:base身份和配置隔离保持原样。
3. 优先级推荐与列表循环统一一级方案选择、名称编辑、启用／使用、添加技能工具栏以及底部右侧“保存配置”。行内策略、排序和删除按固定列排列。
4. 技能列表卡片、滚动区与窗口高度联动，下沿与滚动内容之间留白。高窗口可扩展至880逻辑单位；列表循环的循环设置位于列表之后。
5. HUD外观标签样式位于页首，其后为位置／缩放和图标大小／间距。数值控件采用三列，范围与标签留在左列，滑动条和输入框在独立列；隐藏原生滑块自带重复文字。
6. 标签缩放可输入小数，偏移可输入负数，整数参数仍拒绝小数；错误保留原输入，未修改既有保存和焦点语义。
7. “整体文字→目标距离”可调整显示、字号、颜色、缩放、锚点和偏移，reload保留。旧配置缺字段补默认值；样式隐藏不改变距离采样或策略条件。

## 检查与限制

新增回归覆盖页面标题顺序、职业显示、保存区及策略按钮一致性、列表下沿在视口内、滑动条与输入框无水平交叠、小数／负数输入、距离样式显示／隐藏与重载。快捷键回归验证旧覆盖字段不生效、绑定冲突不能被覆盖、控制键仍不能派发技能、UNKNOWN仍阻断。

交付前通过独立契约检查、301项运行模拟、234项APL模拟、235项Python测试及17项子测试、229项TEK单元测试、2项插件工具模拟、Python编译、51个Lua文件的5.1语法、155个Markdown文件中文检查和差异检查。TEK单元检查首轮并行时出现一项启动时序失败，单独复跑全部229项通过；未改动TEK运行代码。离线布局几何及输入模拟不证明实际中文字体、不同分辨率菜单边缘、真实按键或游戏成功。

## 实机验收

打开派发总览，检查当前配置位于运行模式之后、快捷键位于最下方，不再出现覆盖选项；输入已有绑定的键应报冲突。

分别打开列表循环与优先级推荐，对照保存位置、名称编辑和添加工具栏；滚动最大技能列表，确认上下边界可见且末项可达。缩小游戏窗口后检查边界与保存操作。

打开HUD外观，应先看到标签样式。进入整体文字选择目标距离，调整字号、颜色与偏移，测试隐藏及reload保留。随后检查图标大小和间距的三列控件、负偏移、小数缩放与错误输入，确认没有文字或控件交叠。
