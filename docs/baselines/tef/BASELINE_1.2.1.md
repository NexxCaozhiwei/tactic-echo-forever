# TEF 1.2.1 基线

日期：2026-10-15。以前一基线1.2.0为基础，修复设置界面交互；TEAP协议、技能资格及桌面输入路径保持既有契约。

## 行为范围

- 技能组按钮操作先校验并收集名称、轮数和次数，避免刷新覆盖未保存输入。
- 切换编辑面板只暂存父列表草稿；显式保存写入配置并停止旧派发。退出未暂存修改和清空操作需要确认。
- 主窗口按 UIParent 尺寸缩放，宽屏并排、小屏覆盖显示右侧编辑器；保留相同布局模式下的拖动位置。
- 策略表单复用框架和文字对象，清理旧回调及同步注册；自动攻击6603隐藏无效跳过设置。
- 通用按钮与滑块具有悬停说明、状态反馈；数值框避免重复提交，错误提示保留至有效提交。

## 检查与限制

新增回归覆盖输入保留、退出确认、25次表单重建的框架数量稳定、两种屏幕布局、6603显隐及数值提交次数。交付前已通过README要求的独立契约检查、301项运行模拟、221项APL模拟、235项Python测试及17项子测试、229项TEK单元测试、2项插件工具模拟和Python编译检查；全部51个Lua文件通过5.1语法检查，152个Markdown文件完成中文自然语言审查，差异格式检查通过。

模拟无法验证客户端字体、实际分辨率和缩放下的视觉效果，不能证明钩子、SendInput或施法成功。

## 游戏内验收

执行 `/reload`，检查设置标题版本1.2.1。编辑技能组名称、轮数及次数后切换不可用跳过，确认输入保留。切换策略再返回组编辑，确认草稿仍在且未隐式保存；显式保存后重载核对。

退出未暂存编辑时分别测试取消与确认；清空步骤／条件也测试取消。缩小游戏窗口，检查编辑器完整可见、可滚动及可关闭；宽屏下检查并排显示。反复更换条件、技能和条目，检查没有旧回调串入其他技能。
