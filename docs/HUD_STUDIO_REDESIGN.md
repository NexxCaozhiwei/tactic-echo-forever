# HUD精简版改造

日期：2026-10-16。基于2.0.0继续开发，版本号不变。首轮约460×228的HUD已被本轮260×88精简布局替代；旧检查与部署记录不代表本轮通过游戏实测。

## 当前布局

| 区域 | 已实现行为 |
| :--- | :--- |
| 总体 | 固定260×88逻辑单位，整体缩放上限1；旧缩放值保留但实际显示限制在预算内。 |
| 主技能 | 默认44×44，左上坐标6、8；冰蓝圆角描边，右上仅显示已解析键位角标。 |
| 名称与状态 | 名称从56、10起，最多14字号；一行状态与圆点位于其下，保留运行、停止、待命、阻断及未知区别。 |
| 预览 | 默认两格28×28，靠右放置；移除预览键位、技能名和重复状态。 |
| 进度 | 3单位高细条，只显示公开的当前施法／引导进度，不重复显示技能名或秒数。未知、过期和代次变化时零填充，不推测成功。 |
| 底行 | 固定序列显示步骤与本步精确成功次数；APL显示“优先级推荐／候选预览”，维护显示“增益维护”。 |

技能ID、来源／方案、估测距离、完整技能名、完整键位、组轮次、施法时间和详细阻断原因移到主图标悬停提示。移除大标题、常驻ID、操作说明、独立状态胶囊、多段步骤条和额外分隔框。

## 圆角与线框

外框采用8单位圆角及内侧细描边，主技能框采用6单位圆角、预览采用4单位圆角；键位角标使用相同造型。填充和描边分别使用九宫格纹理，拉伸时保留角部弧度及线宽，避免用客户端装饰性Tooltip边框近似设计稿。

本项目生成以下独立透明TGA素材，不依赖外部游戏美术导出：

- `Media/HUDRoundedFill.tga`：圆角填充。
- `Media/HUDRoundedBorder.tga`：抗锯齿细描边。
- `Media/HUDIconMask.tga`：技能与悬停叠色遮罩。
- `Media/HUDStatusDot.tga`：状态圆点。

生成命令为 `python "Tactic Echo Forever/scripts/generate_hud_media.py"`，开发依赖包含Pillow；素材同时进入插件打包及部署清单。填充、边框和角标复用已创建的纹理，不随刷新重复创建同规模控件。

## 配置与运行边界

旧图标大小、间距、文字样式、缩放、偏移和位置数据保留，不重置用户配置。精简布局固定锚点，并限制实际字号、图标和间距，避免旧的大尺寸设置将HUD撑开。名称、进度与主键位的颜色及显示开关仍生效，非显示标签的选择项禁用。设置中的尺寸和整体缩放范围同步反映精简上限。

保留主图标左键启停、右键设置，空白区域公开脱战且未锁定时可拖动；隐藏HUD只改变显示。冷却、充能及距离仍走既有显示路径，减少常驻数字，不改变State、Recommendation、Runtime、Dispatch、TEAP、TEK、输入资格、宏或绑定。

施法信息沿用Safety规范化和缓存，复用原显示节拍，不新增计时器、事件、钩子、施法轮询或输入路径。APL预览仍来自原只读快照，不表示下次必定施放；精确成功回执仍是次数和步骤推进依据。

模拟回归覆盖260×88尺寸、48／32图标布局、主技能与预览层级、圆角素材及遮罩接入、细进度条、未知／过期信息、APL预览区别、旧配置约束、悬停元数据及纹理复用；原启停、拖动、隐藏、冷却及精确回执回归继续执行。

游戏内以下项目仍为未测：

1. 重载后检查外框与技能框的圆角、细描边、透明角部及遮罩，无方形底色漏出或文字被盖住。
2. 检查技能名、键位角标、状态圆点、底行两端及细进度条均在260×88内；明亮／黑暗场景及不同UI缩放仍可辨识。
3. 运行、停止、阻断、未知和引导时分别检查状态；只读动画不得显示为成功或授予输入资格。
4. 检查主图标悬停详情、预览关闭、进度显示开关、左键启停、右键设置及锁定／拖动。
5. 检查旧的大字号及缩放设置不会扩大占地；确认APL不显示固定序列步骤计数。

概念图只规定目标，离线渲染仅用于控件及素材检查；均不能代替游戏客户端视觉和鼠标交互验收。

## HUD方案定位

用户已反馈260×88版本落地效果良好，将该版本定位为“标准HUD”。这代表用户对当前使用效果的认可，不扩展为所有客户端、分辨率或输入路径已通过实测。

已实现“迷你HUD”：156×60，主图标44、两格预览各36，只保留键位、状态圆点、固定序列次数及底部施法细条；优先级推荐隐藏固定次数。完整名称、状态与诊断信息保留在主图标悬停中。

两版右上角均提供8×8切换按钮，脱战且战斗状态公开时可用。按用户要求采用小尺寸按钮，作为默认控件目标尺寸的明确例外；模式选择保存在自身配置中，默认标准HUD。切换只改变显示，不重置派发意图、进度或回执，不改变隐藏HUD状态。迷你版使用固定图标尺寸，标准版保留原有几何偏好。

迷你版省去常驻状态文字，以圆点配合悬停状态文字呈现；此为用户要求少量信息的布局取舍。离线回归与部署不代替游戏内视觉、点击及重载持久化验收。
