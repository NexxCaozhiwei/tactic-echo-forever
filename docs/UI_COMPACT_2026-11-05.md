# 设置界面紧凑化首版

日期：2026-11-05。版本保持2.0.1。

用户要求提高同页内容密度。本轮将共享普通按钮及输入框默认高度由32改为28，保留14号正文字体；显式设置高度的特殊操作区保留。现有列表控件原本已为28，本轮不进一步缩小列表点击区域。

底部诊断区由大窗口默认展开改为默认收起，保留64单位的操作及摘要区域；点击追踪、问题或输出标签展开，再次点击当前标签收起。收起时隐藏详情滚动区，但不停止已有只读采样、不丢弃诊断数据。列表循环、优先级推荐、增益维护与技能组共用该布局。

在足够高的窗口中，可将约100单位高度归还技能列表。以现有两行技能的88单位步距计算，常见窗口可增加一条完整技能行；具体数量取决于分辨率和缩放。较小窗口原本就收起底部区域，增益不相同。

第二步压缩共享策略编辑器：条件不再一律占192单位高度。简单布尔条件84、数值区间与带观察ID条件140、目标类型124、失控状态112、CDM及带范围档位的敌人数条件176；每张策略卡片顶部44、卡片间距8。字段标签与数值同列，选择状态与观察ID同排，CDM选择入口和必要提示保留。顶部技能参数的行距由40收紧为36，选择分组步距由68收紧为60。此项适用于列表循环、优先级推荐、增益维护及组内共用条件编辑器；策略求值、保存与运行门禁不变。

第三步合并独占整行的操作：技能ID、ID替换、拖入替换、条目体检共用一排；最高已学等级替换与启用开关共用一排；触发方式和额度范围各占半排，保留共同说明。组父项不显示技能替换，体检与启用同排；原组触发仍保留完成后等待重触发的说明。短标签只改变呈现，不改变选项对应的配置值或回调。

后续修正：优先级技能组行将状态、技能组编辑、组摘要分列，避免第二行按钮覆盖状态。列表拖动改为移动到所指条目的位置，修复相邻向下拖动因落点额外减一而无效的问题；拖到列表空白尾部仍移至末项。技能行高度改为76、步距80，保留第二行28高控件和上下箭头。库中技能的拖入插入语义保留，与列表内部排序使用不同的落点提示。

用户实测仍失败，但拖动时能变半透明，确认原生开始事件已触发；先前直接调用停止事件的模拟未覆盖原生释放链路。新增按公开鼠标坐标、条目矩形和有效缩放计算落点，并要求坐标在列表可见视口内；无法读取几何时保留原悬停判断。鼠标释放也可完成已有拖动，随后的停止事件幂等返回。新增开始、落点、无落点及隐藏取消的有界诊断记录。回归模拟覆盖悬停为假、半倍缩放、鼠标释放后停止及视口外拒绝；这不能证明客户端实际失败已修复，需重载后实机复测并立即落盘。
