# Studio第一、二阶段实现与验收

本文保留第一、二阶段的历史范围；当前工作区已继续整合，最新行为见[整合验收候选](STUDIO_ACCEPTANCE_CANDIDATE.md)。

日期：2026-10-16。基于提交 `361e439`，版本号保留 `1.3.1`；本交付为待实机验证的开发包，不声称已发布新版本。

## 一、范围与架构

本轮只实现第一阶段外壳及第二阶段主列表迁移。附件中的完整五阶段要求作为后续设计参考，不把后续阶段计入本轮完成范围。

`UI:CreateSettings()` 创建原有编辑控件后，通过 `UI:CreateStudio()` 包装为标题区、活动栏、工作区、主编辑器标签、摘要栏、底部输出占位和状态栏。窗口宽度最多1280、高度最多900逻辑单位，按 `UIParent` 可用尺寸适配；工作区在有效宽度不足940时折叠，摘要栏在不足1240时折叠。极窄于680逻辑单位的视口仍需缩放，不能声称完整可读。

主编辑器复用原有方案工具栏、草稿、列表滚动控件和保存按钮。没有创建新的保存格式或数据库字段。新增标签的 `.apl` 和 `.sequence` 只是界面名称。

## 二、原有编辑调用及保存路径

| 对象 | 草稿与编辑调用 | 持久化路径 |
| :--- | :--- | :--- |
| 列表循环 | `DraftRows`、`WriteDraft`、`AddSequenceSpell`、`EditSequenceRow`、`OpenSequencePolicy`；按职业及方案保留会话草稿。 | `Profiles:Save`，继续保存到 `TEF_DB` 的原职业方案。 |
| 优先级推荐及维护 | `customDraft`、`customDraftCache`、`AddCustomSpell`、`CommitCustomNumbers`、`RefreshCustomAPL`。 | `APL.Custom:Save` 或 `Maintenance:Save`，使用原校验及运行失效处理。 |
| 技能组 | `OpenSkillGroup`、`groupDraft`、`CommitGroupFields`、`SaveSkillGroup`；暂存写入父列表草稿。 | 显式保存仍保存技能组及所属方案；退出未暂存修改仍使用原确认。 |
| 策略 | `CustomRow`、`RefreshStrategyForm`、`ChangeCustomStrategy`、`CommitCustomNumbers`。 | 原策略保存按钮调用所属列表的保存接口；摘要不拥有策略副本。 |

打开、关闭及切页继续经过原数值提交和确认流程。会话草稿跨页保留；关闭不自动保存，重载前必须显式保存。打开设置继续暂停派发并保留运行意图；标题栏启停仅调用 `Runtime:ToggleIntent`，设置门禁仍阻断派发。工作区导航只选择编辑对象，“使用本方案”继续负责切换实际来源。

## 五、状态、拖放和性能边界

草稿没有与其内容严格对应的实时求值身份；APL行显示 `UNKNOWN`，停用行显示 `DISABLED`。这不表示已检查条件为假，也不表示可以派发。不从已保存列表的旧快照猜测草稿就绪状态，不自行生成 `READY`、`ACTIVE` 或 `BLOCKED`。列表循环继续按固定尝试语义展示，不增加就绪门禁。

状态栏读取 `Runtime:GetViewState`、插件版本及传输开关；没有桌面端连接证据时明确显示“TEK连接：未确认”。开启TEAP输出不等于桌面端已连接。

规则拖动降低源行透明度，目标行前显示蓝色插入线。向后移动时补偿移除源行带来的索引变化；空白落点追加到末尾，取消不改变顺序。外部光标身份不能确认或达到容量时保留草稿及光标。原上下箭头仍可替代拖动。

每种父列表仍预建16行，原组编辑器仍预建8行；插入线首次使用时创建一个并复用。没有新增定时器、钩子或逐帧扫描；摘要和插入线复用现有界面刷新。布局尺寸、页面签名未变化时不重复重排，普通刷新不创建列表行。原策略表单继续使用复用池。
