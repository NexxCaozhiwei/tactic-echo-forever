# CDM默认ID目录

日期：2026-10-26。版本保持2.0.1。本轮针对用户确认的观察ID手输错误，增加从CDM原生公开目录选择观察身份的功能。

## 使用方法

1. 游戏内`/reload`，打开TEF设置，进入对应技能的“编辑策略”。
2. 对CDM增益或冷却条件，点击“选择CDM技能”。
3. 列表显示当前CDM目录中的技能名称、图标及默认观察ID。按名称或ID搜索，点击“刷新”重新读取。
4. 点击条目右侧“选”，将默认ID填入当前条件草稿；确认后点击原来的保存按钮。原有手输ID保留。

列表循环、优先级推荐、增益维护及技能组内条件共用同一入口。选择观察ID不更换要施放的技能，不自动保存、不修改现有其他条件，也不改变运行意图。

## 数据与边界

- 只读取`C_CooldownViewer`当前公开目录中`GetCooldownViewerCooldownInfo`提供的精确`spellID`，不读取其他插件的SavedVariables。
- 默认ID列表与运行时CDM身份匹配使用相同字段。目录项存在不代表技能可用、增益存在或冷却结束；实际帧与派发门禁继续独立复查。
- 不使用同名、最高等级、`overrideSpellID`或`linkedSpellIDs`猜测对应关系。同名不同ID分别保留；完全相同ID跨面板重复时只显示一次。
- 每种类型最多读取两个目录、每目录128项，总计最多256项。缺失、受限或超容量的部分标记未知，不添加猜测ID。
- 仅在打开、手动刷新及选用前复核目录；搜索使用缓存，不增加运行心跳或逐帧扫描。
- 复用现有8行列表、搜索及滚动控件。CDM模式不套用动作条筛选，不允许拖拽成施放技能；关闭后恢复已学技能库模式和原筛选偏好。
- 条目选用前重新检查目录与当前编辑身份，防止目录变化、切换技能或删除条件后误写。
