# 技能组首版说明

本功能纳入 1.2.0 基线，开发阶段使用 1.1.12 验证。技能组嵌入列表循环或优先级推荐的配置行，不增加独立输入通道；每处组独立保存名称、步骤、策略与循环轮数。

## 编辑方式

在技能列表点击“新建技能组”。组行保留排序、删除及“编辑策略”，在策略按钮前新增“技能组编辑”。右侧组编辑框提供名称、循环轮数、拖入技能、ID 新增、组内拖拽／箭头排序、单技能策略、使用次数、不可用跳过、保存、清空及退出。

每组最多 8 步，不允许嵌套；每步使用次数为 1～99，组循环轮数为 1～99，默认一轮。清空仅修改草稿；保存同时保存所在父列表并停止派发。退出丢弃未保存的组草稿。组内“编辑策略”与组编辑框在右侧同一位置切换，关闭策略框返回组列表。

组内技能列表有独立外框，拖入按钮、列表空白、滚动区域均支持追加；拖到已有条目时插入其前。未接纳的技能保留鼠标游标。打开组内或父列表策略前，先保存当前组及父列表并隐藏组编辑框；保存失败不切换面板，避免重叠或丢失编辑内容。

## 执行约定

- 组策略决定是否进入；进入后按组内顺序完成，不接受普通优先级技能抢占。组内策略继续实时检查，明确不满足跳过，未知等待；不可用跳过保留既有公开性要求。
- 列表循环完成组后继续父列表下一项；优先级推荐完成组后从最高优先级重新判断。同一触发状态下已完成的优先级组不立即重进，组策略明确不满足后再满足、目标选择改变或重新手动开启才可重新触发；无策略组每次开启或目标选择周期只执行一组轮次。
- 精确技能的起始与成功回执推进当前子步骤，失败不推进。组入口本身不派发首技能，不把单次首技能成功当作整组完成。首版不跨组入口提前排队，组内也不提前排队。
- 手动停止保留组内进度，再次开启可继续；配置编辑、重置、重载、世界切换和致命错误清除进度。目标选择改变、公开目标死亡或消失会结束本次组，列表来源继续组后项。
- 战斗来源的技能组必须确认公开战斗状态。增益维护保留原优先级，在当前施法结束后插入，之后恢复组内位置与次数。
- HUD 显示活动组名称、子步骤、循环轮数与当前技能次数。日志记录组进入、下一轮、完成、目标变化中止，以及有界组进度字段。

## 验收步骤

1. `/reload`，在列表循环建立“寒冰箭组”，加入已学且动作栏有按键的寒冰箭一次、火球术两次，循环设为两轮，组后放一个不同技能。保存并关闭设置。
2. 对单个存活敌人开启派发，观察约 30～60 秒；确认按组内顺序与次数成功，完成两轮后才执行组后技能。中途停止再开启，确认不重放已成功的子步骤。
3. 在组与子步骤分别加入移动条件，检查进入条件、组内跳过及未知阻断。测试组内拖拽、箭头、清空草稿、退出及保存后重载。
4. 在优先级推荐中建立相同组，将普通技能置于组后；确认进入后保持顺序，完成后普通技能能被推荐，同一触发状态不无限重新进入。
5. 测试增益维护插入及目标切换；测试结束 `/reload` 或退出游戏落盘，以本插件数据核对顺序、计数和中止原因。

本地模拟不证明游戏内实际派发、布局或拖拽手感通过；仍需上述游戏验收。

## 起手与循环修复

2026-10-15：落盘会话 54、56 出现首发奥术冲击成功却被标记为 `GROUP_NOT_ENTERED`，随后自动再次施放冲击。现从公开精确 `SENT/START` 接续当前符合策略的组首技能，仍须同一身份的精确成功才推进；成功事件本身不能反推进入。优先级来源还必须匹配当时最高优先级候选，组内首技能策略也要满足。公开脱战阶段仅保留手动起始回执，不授予输入资格。

同批修复组尾误使用父列表循环开关的问题：组内完成一轮后由组的轮数决定下一轮或退出，父列表循环仅在返回父列表后生效。引导技能在开始时收到成功回执后，等待公开引导结束再进入下一轮，避免提前结束整个组。

回归覆盖父列表循环开启时的三轮组、脱战手动起手接续、优先级冲突拒绝、失败／重复／受限身份不推进，以及末项引导成功后等待结束。实际游戏验收需保持同一目标，配置冲击一次、飞弹一次及三轮，手动冲击起手后观察约 30～60 秒，再落盘核对顺序与 `GROUP_NEXT_ROUND`。
