# 方案分享实现与验收说明

日期：2026-11-10。随2.1.0发布。本轮实现单套方案、单项策略和当前职业六套方案整包分享；独立技能组和增益维护整套分享留待后续。

## 数据与边界

`PlanShare.lua`定义`TEFPLAN:1:校验值:数据`格式。正文采用有长度前缀的纯数据序列化及Base64编码，Adler-32用于发现复制损坏，不提供作者身份或可信来源证明。格式版本独立于插件版本；首版不接纳未知格式版本。

序列化和解析均限制正文4MiB、分享文本6MiB、深度20、节点600000、单表64项及单文本字段2048字节。解析不执行Lua代码，不接受循环或带元表对象、重复字段、未知字段及非连续列表。父列表16项、组内36步、策略与条件各8项等限制继续由现有清洗器复核。

包含方案名称、职业、来源类型、技能精确ID及顺序、次数、使用限制、目标类型、触发行为、使用／跳过策略和组内轮数／退出设置。不包含运行身份、回执、计数、日志、快捷键、HUD、启用状态、全局循环／重置或派发窗口。精确等级未学和按键未核对均仅作为本机提示，不自动升级或授权输入；CDM身份要求在本机另行核对，不把当前无法观察解释为增益不存在。

## 交互与保存

方案设置中的两个入口同行排列。导出当前编辑草稿，包含未保存条目；已输入但未点击保存名称的文字不作为方案名称导出。分享窗口使用多行输入、预览滚动区、目标槽选择和固定底部操作；窗口复用，不随重复打开创建同规模控件。

解析时不修改草稿或配置。确认覆盖时固定目标槽、编辑器身份、名称及目标草稿指纹；确认后重新核对，已改变的目标拒绝覆盖。确认取消、损坏文本、不同职业／来源及容量错误均不替换原草稿。导入后方案名称作为会话草稿随显式保存落盘；重载前必须保存。导入不调用派发、方案启用或运行来源切换接口，常规保存继续遵循现有停止与重置契约。

## 验收状态

本轮离线回归覆盖两种来源的36步组、策略及名称往返、损坏校验、错误职业与类型、超限、嵌套、未知字段和非法纯数据结构；覆盖导入前后保存配置与运行意图不变、显式保存名称、解析失败、取消与过期草稿拒绝覆盖。具体通过结果以本轮交付输出为准。

游戏内字体、中文显示、输入框长文本、滚动、焦点、Ctrl+C／Ctrl+V、不同缩放下控件遮挡及覆盖确认点击穿透均未测。请在宽屏和窄窗口分别导出一个有技能组的方案，导入另一个槽位，确认预览提示、保存后重载内容一致；再分别取消覆盖、粘贴坏码、关闭设置及重复打开25次。离线检查不证明实机验收通过。


## 后续整合：策略、整包与输入框

`TEFPOLICY:1:`仅包含职业和使用／跳过策略，允许在当前职业各编辑来源间复用。覆盖确认绑定编辑对象、索引及完整条目指纹；改变目标或旧条目后拒绝应用。目标技能ID、次数、目标类型及触发行为保留，CDM等显式观察ID保留；无观察ID条件指向导入后的目标技能。保存仍经原方案或组保存接口执行。

`TEFBUNDLE:1:`必须完整包含当前职业列表循环和优先级推荐各三套方案，拒绝缺槽、跨职业、混合来源及超限内容。导入先替换全部草稿；统一保存会再次清洗和审计全部六槽，全部通过后才调用一次重置并写入六套配置与名称。运行来源、启用状态、选择槽、HUD及派发参数保留；保存停止旧意图。独立方案与策略、整包码不可混用。

导入框原先直接使用多行编辑器自身背景，空文本时客户端可能把编辑器压到一行。现在以独立164高输入底板承载148高滚动视口，编辑器不再承担外框；点击底板或视口空白区域可聚焦。导入与导出复用同一窗口。

新增离线回归覆盖输入外框尺寸与复用、策略码往返及四种编辑来源只改策略、整包六槽名称与组内36步往返、导入不落盘、统一保存后重载一致，以及非法槽导致统一保存失败时原配置保留。客户端输入、缩放和视觉仍需实测。

## 动作条等级替换

新增按需扫描的动作条等级检测，候选由公开动作槽精确ID或经核对宏提供，逐ID检查已学与主动状态；同族名称只用于发现候选，不提供输入授权。多个等级、未知或未核对按键均阻断替换；宏无法精确核对时不作为候选。没有新增心跳、计时器、宏修改或绑定写入。

单项替换复用原策略技能替换接口。批量检测递归处理当前父方案及组内步骤，形成草稿替换预览与明细Tooltip；确认时复核草稿身份和动作条候选。保留策略、次数、行为及显式观察ID，并重建父组首项展示ID。替换不会自行保存或启用派发。离线需覆盖歧义、受限、未学、未绑定、确认期间动作条变化及组内条目；实机未测。
