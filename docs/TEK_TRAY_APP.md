# TEK 状态窗与托盘

TEK Windows UI 提供运行状态、最近阻断原因、诊断入口、开始/暂停控制与紧凑显示。状态窗不是派发授权来源；实际授权仍由 AddOn 的 TEAP 状态与 TEK 安全门禁共同决定。

当前需要 Windows 实机确认的项目：托盘恢复、最小化后状态更新、多个 WoW 客户端时的前台识别、管理员权限差异和 Defender/杀毒软件提示。
