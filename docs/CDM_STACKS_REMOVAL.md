# 移除CDM增益层数条件

日期：2026-10-15。版本保持1.3.1，作为该版本的后续修正。

会话61配置奥术飞弹观察400574的3～4层，保留的16条记录均为 `CDM_FRAME_ID_UNKNOWN`，没有公开层数值。奥术冲击成功次数不能代替当前增益层数，不能继续把此条件作为已验证能力提供。

## 当前行为

- 从列表循环、优先级推荐、技能组及增益维护的共享新增条件菜单中移除CDM增益层数。
- 原有 `cdmStacks` 只用于兼容读取和删除，不再请求层数采样，也不能通过旧快照取得满足结果。诊断标记 `CDM_STACKS_REMOVED`。
- 旧条件显示“已移除”，不再提供层数和目录ID编辑框；可以删除或更换为其他条件后保存。含旧条件的使用或跳过策略继续按未知处理，不能因条件移除而隐式授权。
- 不修改游戏WTF文件。用户在游戏内删除条件并保存后，由游戏正常落盘。建议使用奥冲固定次数后接飞弹的技能组。
- CDM增益活动、冷却活动条件保持原行为；历史基线和历史说明中的层数描述属于当时实现，不代表当前功能。
