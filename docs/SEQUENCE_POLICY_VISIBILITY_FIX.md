# 列表循环策略面板显示修复

日期：2026-11-10。版本保持2.0.1。

## 问题与修改

检查区原先只在点击时显示策略面板，布局同步只处理隐藏，没有根据当前选择恢复显示。当前选中条目仍然有效但面板被隐藏后，重复刷新布局不能恢复，可能留下空白检查区。

布局同步现在根据当前列表来源、选中条目和策略编辑来源恢复策略面板。方案设置及非列表页面继续隐藏策略面板。修改不改变策略内容、保存接口或派发资格。

## 验证记录

| 项目 | 结果 |
| :--- | :--- |
| 宽屏与窄屏下，方案设置与列表策略往返 | 通过，离线模拟 |
| 当前策略面板隐藏后，重复布局及页面刷新恢复显示 | 通过，离线模拟 |
| 第二条技能的编辑身份正确 | 通过，离线模拟 |
| 字体、中文、间距、对比度、控件遮挡、点击穿透 | 未测，需游戏内检查 |
| 输入保留、保存生效、取消保护、焦点与快捷键 | 沿用现有接口，本轮实机未测 |
| 最大表单滚动与连续重建资源复用 | 本轮未新增表单或控件，实机未测 |

游戏内请进入列表循环，打开方案设置，再编辑不同技能的策略；在较窄窗口重复，并在切页返回后再次编辑。确认检查区显示所选技能的条件，方案设置与策略不会同时覆盖。离线回归不代表游戏内视觉验收通过。
