# 自定义 APL 策略条件设置改版草稿

本改动纳入 1.1.0 基线，开发阶段使用 1.0.23 验证。离线测试与部署校验不等于游戏内验收。

## 页面布局

- 方案一、方案二、方案三单独占一行。
- 拖入技能后依次放置精确技能 ID 输入框和 ID 新增按钮。
- 技能列表增加明显外框。拖动技能条目到另一条目可调整顺序，保留上下箭头。
- 点击编辑打开紧贴主设置窗口右侧的“策略条件设置”。切换到其他设置页面时关闭此窗口。
- 加号新增策略，每个技能最多 8 条策略，每条策略最多 8 个条件。支持添加条件、删除条件、删除策略、保存和清空。

## 判断语义

- 每条策略中的条件以 AND 组合。
- 所有使用策略均须满足；不满足则继续检查后面的技能。
- 任一跳过策略全部满足，便跳过当前技能；跳过优先于使用。
- 没有使用策略时，按基础可用性与跳过策略判断。
- 未知条件不授权使用；不把缺失 CDM 帧当成非活动或不存在。
- 这里的跳过是本次优先级求值继续检查后续技能，不是人工序列的计数推进。成功后仍重新求值。
- 已学精确技能、可用性、资源、技能射程、目标、战斗及输入链门禁仍需满足。

## 条件

| 条件 | 含义 |
|---|---|
| 技能可用性 | 公开可用且资源不不足；明确不可用或资源不足时为不可用 |
| 技能范围 | 当前技能对目标的公开范围布尔 |
| 目标距离 | 可输入上下限，包含边界；单边留空表示不限 |
| 移动状态 | 移动中或站定 |
| 可见敌人数 | 可见敌方姓名板数量上下限，不代表周围指定码数或实际命中数 |
| CDM 冷却状态 | 指定目录精确技能 ID 的冷却帧活动状态；可用表示非活动 |
| CDM 增益状态 | 指定目录精确技能 ID 的增益帧活动状态；存在表示活动，不等同于真实光环证明 |
| 技能是否 CD | 保留原先的自身冷却活动条件，供旧配置迁移与继续编辑 |

CDM 条件可添加多次，同时判断不同技能的冷却与增益。ID 留空使用当前技能 ID。派发前重新读取条件，避免缓存候选在状态变化后继续派发。

旧移动、距离、冷却活动和 CDM 条件在编辑草稿中迁移成使用策略，保存前不改变已保存配置。旧距离比较符保留严格与非严格边界，重新选择目标距离可改为上下限形式。清空只清除当前技能条件草稿；保存后生效。保存整套配置会停止派发。

## 游戏内验收步骤

1. 输入 `/reload`，打开自定义 APL。确认方案标签独占一行、ID 新增位于拖入技能后。
2. 拖入两个已学且已有直接按键映射的技能。拖动前一个条目到后一个条目处，再用上下箭头恢复顺序，确认技能及其条件一起移动。
3. 点击技能编辑，在右侧新增使用策略，添加目标距离 20～30 码。保存后关闭设置、进入战斗开启派发；在范围内外分别观察约 15 秒，确认范围外改选后续合格技能。
4. 为另一技能新增跳过策略，选择技能可用性为不可用。验证资源不足时不派发该技能，恢复资源后可重新成为候选。
5. 同一使用策略添加目标距离上限 20、指定技能 CDM 冷却可用、另一技能 CDM 增益存在。观察约 30 秒，确认全部满足才选中，任一不满足或未知则检查后续技能。
6. 再添加一条使用策略，确认两条使用策略均满足才使用；加入满足的跳过策略，确认跳过优先。
7. 测试清空、保存、方案切换与再次 `/reload`，确认各方案独立且条件保留。退出游戏或再次 `/reload` 使日志落盘，再分析当前插件的保存数据。

姓名板 10 码敌人数统计不属于本次改版，当前可见敌人数条件仍使用既有全体可见姓名板统计。
