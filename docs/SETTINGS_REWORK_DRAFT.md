# 1.0.23设置界面改版说明

本轮设置界面改版已收敛为1.0.23；按用户明确请求提交并同步。派发行为调整留待下一轮。

- 派发总览的当前配置选择人工序列或自定义APL；循环/重置移入人工序列。
- 诊断/测试和场景/验证导航入口隐藏，底层诊断与开发接口保留。
- 人工序列、自定义APL各有方案一、二、三，配置互相独立，同一时间运行一个来源的一套方案。首次默认选择并启用方案一，其余默认停用。用户显式启用后点击“使用本方案”；切换停止派发，关闭设置后重新开启。
- 旧单体数据迁为方案一、旧多目标数据迁为方案二，方案三为空。内部旧键只为数据兼容保留，不再作为界面目标数量概念。以后重载保留用户已保存的方案选择和启用状态。
- 人工序列取消“采用已观察变形术ID”和“高级文本”入口，拖入技能、精确ID新增、逐行编辑及保存保留。隐藏文本载体仅作内部草稿序列化，不向用户展示；旧超16步配置仍保留，逐行删减后才能保存。
- HUD图标大小与间距支持滑块和整数输入，回车或失焦应用；主图标32–112，两张预览24–96，两段间距2–40。越界、空白或小数不应用，显示允许范围。战斗中延后实际布局。

方案切换继续使用唯一Runtime意图和既有重置/身份失效链，不增加输入路径。保存未启用APL方案只保存数据，不启用或切换该方案。

本地检查与文件部署不代表游戏内布局和配置迁移的实机验收。下一步应重载检查各页、分别编辑和启用第三方案、验证数字输入及两种来源切换后当前方案显示，并再重载确认配置保留。
