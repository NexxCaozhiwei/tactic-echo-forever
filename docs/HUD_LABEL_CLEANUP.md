# HUD预览修复与标签清理

日期：2026-10-18。版本保持2.0.0。本轮仅调整显示与外观设置，不改变派发或精确成功回执。

## 引导末步预览

会话72显示：技能组末步奥术飞弹在引导起始收到精确成功回执，组内步骤标记完成，但组仍等待引导结束。旧HUD直接根据步骤完成标记隐藏预览卡。

现在仅在整个列表完成、且没有活动技能组时按完成状态隐藏预览；组内末步完成后仍显示现有推荐层给出的三格内容。引导中不把主卡名称改成“完成”。关闭预览开关仍会隐藏预览，普通列表完成后的原行为保留。

该修复不提前恢复父列表、不推测引导成功、不解除引导门禁，也不改变技能组轮次和成功计数。

## 标签核对

| 项目 | 当前处理 |
| :--- | :--- |
| 主卡键位 | 保留显示、字号、缩放、描边及颜色；位置固定在键位框中央。 |
| 技能名称 | 保留样式；仅标准版显示，完整名称在悬停中。 |
| 进度行与次数 | 保留样式；标准版固定显示，迷你版仍可关闭次数。 |
| 预览卡键位、充能文字、冷却数字、卡片状态和卡片标题 | 删除失效设置及始终隐藏的文字节点。 |
| 距离文字 | 删除失效样式和隐藏文字节点，估测结果改为只读字符串，继续供悬停及诊断使用。 |
| 来源文字、技能ID、预览标题、预览说明、操作提示 | 删除隐藏节点，仍需使用的详情直接生成在悬停中。 |
| 步骤装饰条和旧分隔线 | 删除始终隐藏的显示资源。 |
| 标签锚点及水平、垂直偏移 | 当前固定布局不采用，删除设置控件及对应配置字段。 |
| 冷却、充能遮罩及超范围染红 | 保留原功能；只移除隐藏的数字标签刷新。 |

旧配置加载时仅保留三类实际使用的标签样式。有效字号、缩放、颜色、显示开关及描边继续读取；失效字段不再创建或持久化。外观设置不改动技能、策略、方案或运行意图。

设置页移除无效模块选择和选项，并收紧空白区域；预览图标大小输入范围同步为实际支持的24～36。

## 截图复核后的设置页修正

- HUD页原三行只读摘要被写入标签卡片顶部，现清空并隐藏，避免与标题和按钮重叠；缩放、锁定和预览开关继续由原控件展示。
- 技能库底板改为不透明深蓝色，条目使用不同底色，外框采用浅蓝色，区别于后方Inspector。
- 新增“仅显示动作条上的技能”开关，默认关闭；只筛选已学技能库，不扩展技能授权。
- 动作条扫描复用现有解析器，范围为1～180槽，按精确技能ID匹配，支持已核对的宏；未知、物品或未收录的精确等级不进入结果。
- 扫描仅发生在开启筛选、重新打开或手动刷新时；普通搜索复用缓存。视图开关不标记技能组草稿为已修改。
- 新增筛选行后，列表和滚动条下移32，按剩余高度重新计算可见行数。

上述修正有摘要隐藏、背景不透明、列表边界、同名不同ID、未知值、宏、搜索缓存及草稿／运行身份隔离的离线回归。清理后的客户端文字、颜色差异、滚动、焦点和点击仍为未测。验收时先打开HUD页确认标题与控件分开，再打开技能库切换筛选、搜索，并移动一个技能后点击刷新；确认只改变列表结果，最后重载或退出落盘。
